# Демонстрация за 5 минут

1. 0:00–0:30. Открыть сайт и /docs. Войти student1. Показать 12 аудиторий.
2. 0:30–1:15. Завтра, корпус B, от 20 мест, проектор. Результат B-101 и B-204. Выбрать B-101, показать занятые и свободные интервалы.
3. 1:15–2:00. Забронировать завтра 14:00–15:00. Показать подтверждение, .ics и запись в «Моих бронированиях».
4. 2:00–3:00. Через Swagger войти student2, попытаться POST /api/bookings на тот же интервал: 409 BOOKING_CONFLICT. Попытаться DELETE чужой брони: 403 FORBIDDEN. Можно показать результат автоматического теста all_eight_acceptance_scenarios.
5. 3:00–3:40. student1 отменяет бронь. Запись остаётся в «Отменённых», слот снова доступен.
6. 3:40–4:30. Войти admin: все брони, отмена чужой, редактирование аудитории, недельная загрузка, CSV.
7. 4:30–5:00. Тёмная тема, мобильный экран. Показать README, Compose, тесты и Render-конфигурацию.

Если слот уже занят после предыдущей демонстрации, выберите другой свободный интервал или отмените свою демонстрационную бронь. Даты в примере относительно текущего дня кампуса.

## Дополнительная демонстрация после обязательных сценариев

Показать рекомендации при поиске по точному интервалу, QR-код аудитории, управление текущей встречей и админские правила. Для закрытия комнаты сначала показать список затронутых броней; проводить отмену только на учебных данных. Квоты по умолчанию выключены, почта не нужна для базовой приёмки.
