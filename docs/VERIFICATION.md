Тесты охватывают восемь сценариев ТЗ, права, пересечения и соседние интервалы, конкурентную запись, миграцию старой схемы с сохранением данных, отзыв и истечение сессий, смену пароля, приглашения, лимиты и безопасную конфигурацию.

Известное предупреждение: Starlette сообщает о будущем переходе TestClient с httpx на httpx2. Все тесты проходят.

Границы проверки: публичный Render-сервис и cron-job.org ещё не созданы — Render требует входа владельца. Git remote не настроен; GitHub Actions подготовлен, но не запускался на GitHub. HTTPS, доставка аварийных уведомлений и managed backups проверяются после публичной выкладки. Длительное нагрузочное тестирование не проводилось. Скрипты backup/restore используют проверенные в drill утилиты PostgreSQL; сам drill выполнен внутри Docker, без внешнего доступа к БД.

Для повторения: README и [PRODUCTION.md](PRODUCTION.md). Локальные секреты и дамп исключены из Git.
